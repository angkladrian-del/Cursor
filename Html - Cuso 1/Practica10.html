Listas y tablas

Listas

Las listas son elementos que permiten organizar información de manera jerárquica.

ejemplo:

Donde la etiqueta ul hace referencia a una lista no ordenada.

  • Elemento A
  • Elemento B

Donde la etiqueta ol hace referencia a una lista ordenada.

  1. Elemento 1
  2. Elemento 2

La diferencia entre las listas ordenadas y no ordenadas es que las ordenadas siguen una numeración o una estructura que va del primero al ultimo ingresado, mientras que las no ordenadas no tienen un orden específico.

    Ejemplo de lista no ordenada de opciones de comida:
  • Pizza
  • Hamburguesa
  • Ensalada
  • Arroz
    Ejemplo de lista ordenada de pasos para preparar un sándwich:
  1. Tomar dos rebanadas de pan
  2. Agregar ingredientes al gusto
  3. Cerrar el sándwich con la otra rebanada de pan
  4. Disfrutar
Existen tras listas más especializadas para ordenar los elementos en orden ya sea alfabetico o numerico, pero estas requieren del apoyo de css o un script para su correcta implementación. Un ejemplo de de codigo scritp para ordenas alimentos en forma alfabetica es el siguiente:

Script
const lista = document.getElementById('miLista');
const items = Array.from(lista.querySelectorAll('li'));
items.sort((a, b) => a.textContent.localeCompare(b.textContent));
items.forEach(item => lista.appendChild(item));
/Script

Tablas

Las tablas son elementos que permiten organizar información en filas y columnas.

ejemplo:
Encabezado 1 Encabezado 2
Dato 1 Dato 2
Dato 3 Dato 4

La etiqueta table hace referencia a coonstruir una tabla.
La etiqueta tr hace referencia a una fila de la tabla.
La etiqueta th hace referencia a un encabezado de la tabla.
La etiqueta td hace referencia a una celda de la tabla. Los border en la tabla sirven para delimitar las celdas y hacerlas visibles, osea delimitar el grosor de las lineas de la tabla.

Menus con listas

Los menús son muy comunes en el uso de listas para organizar opciones de navegación en un sitio web. Normalemnte se utilizan listas no ordenadas (ul) para crear menús desplegables o de navegación lateral.

ejemplo:
  • Inicio
  • Acerca de
  • Servicios
  • Contacto
