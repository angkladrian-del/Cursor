Audio y Video

El audio y videos se pueden utilizar de manera local o en linea las diferencias es que hay una restriccion los audios y videos en linea pueden tener derechos de autor copyright©

La etiqueta video se utiliza para incrustar contenido de video en una página web. El atributo src especifica la ruta del archivo de video que se va a reproducir. En este caso, "localvideo.mp4" es un archivo de video almacenado localmente en el servidor o en el mismo directorio que el archivo HTML.
El atributo width define el ancho del reproductor de video en píxeles. En este ejemplo, el reproductor de video tendrá un ancho de 600 píxeles. El atributo controls agrega controles de reproducción al reproductor de video, como botones de reproducción, pausa, volumen y barra de progreso, lo que permite a los usuarios interactuar con el video.

Audio

El audio tambien presenta las mismas caracteristicas que el video, como las cuales son cargar el audio de manera local o solicitar un audio de internet, pero teniendo cuidado con el copyright.

La etiqueta audio se utiliza para incrustar contenido de audio en una página web. El atributo src especifica la ruta del archivo de audio que se va a reproducir. En este caso, "localaudio.mp3" es un archivo de audio almacenado localmente en el servidor o en el mismo directorio que el archivo HTML.

Esto es un caso de manera local, para un caso de internet

En este ejemplo, se utiliza la etiqueta audio para reproducir el audio, se implementa el atrinbuto type para definir el tipo de archivo de audio que se está utilizando, en este caso "audio/mpeg" para archivos MP3. Es Necesario colocar controls para que el usuario pueda manipular el audio. Solo en cuestiones que sea de fondo en la pagina puede no llevar controles, pero es recomendable siempre colocarlos.

En este caso el audio es libre de querer colocar una cancion de fonde se requiere colocar los elementos de iframe y derechos de autor para no caer en un problema de copyright.

La etiqueta allow permite especificar qué permisos se otorgan al iframe. En este caso, se permite el autoplay, escritura en el portapapeles, acceso a medios cifrados, pantalla completa y miniatura de imagen en imagen.
