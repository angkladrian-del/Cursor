Bienvenido a la pagina principal

Esta es la practica 1 del curso de Universidad Desarrollo Web, con la implementación de un menu de navegación usando las etiquetas de html.

    Inicio | Contacto | Acerca de

Para este nuevo proyecto se implementaron etiquetas de navegacion vistas en otro cursos para reforzar lo visto en otros cursos y tambien en el curso de Universidad Desarrollo Web

Para este nuevo menú se utilizason las siguientes etiquetas

  • <nav>: Define una sección de navegación en la página.
  • <ul>: Crea una lista desordenada para agrupar los enlaces de navegación.
  • <a>: Define los enlaces de navegación que permiten a los usuarios moverse entre diferentes páginas o secciones del sitio web.
  • <li>: Define un elemento de lista dentro de una lista desordenada.
  • <& referencia ;>: Se utiliza para poner acentos y caracteres especiales en HTML sin tener conflictos con caracteres especiales o palabras recervadas.

Recuerde que su pagina de inicio es index.html por lo tanto solo refrescara la pagina cada que precione inicio.
