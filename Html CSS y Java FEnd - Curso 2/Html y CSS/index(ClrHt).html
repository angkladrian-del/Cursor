Colores de html

Para colocar los colores de html se requiere utilizar etiquetas <span> y <style> dentro de las etiquetas <head>, de las etiquetas <p>, esto nos permite cambiar el color de manera nativa en html.

Se utilizo la etiqueta <style> junto con el atributo color para designar el color del texto. Se puede usar los atributos RGB o Hexadecimal también.

Todos estos cambios son de manera individual en cada parrafo o titulo, pero se puede realizar esto de menera general afectando a todos los parrafos declarados y a los tiitulos que tengan la misma etiqueta.
Se declara en el header como <style>
p {
color: blue; }
h1 {
color: red; }
</style>
Los parrafos pueden tener colos independientes cada uno asi como los titulos declarados si y solo si se les aigna un ID como atributo.
