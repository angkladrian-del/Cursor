### 4. venv

**Entorno virtual de Python** para ejecutar scripts del proyecto.

- `conteo_palabras.py` — Lee un archivo de texto, cuenta palabras y puede mostrar las 10 más frecuentes.
- `contador.py` — Script de conteo adicional.
- Resto: `Scripts/`, `Lib/` — Archivos estándar del venv (activación, pip, etc.).

Para usar el entorno:

```bash
# Windows
venv\Scripts\activate

# Luego, por ejemplo:
python venv\conteo_palabras.py
```
